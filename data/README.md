# Data Directory Structure

This project uses a standard data science project structure to keep files organized by their stage in the pipeline.

- `01_raw/`: Immutable, external data. Contains the raw OSM dumps (`.osm.pbf`), census geodatabases (`.gpkg`), and raw CSV downloads from MOBI.E and INE. **Never manually edit files in this directory.**
- `02_reference/`: Static reference files used to map or correct data during processing. Includes `.txt` files defining the OSM tags we care about, and JSON files detailing manual corrections for bad data.
- `03_interim/`: Intermediate data files generated during processing. This includes `osm_analysis.db` (the parsed base map generated by Step 0 scripts) and the corrected MOBI.E csv files.
- `04_processed/`: Final, cleaned data ready for Machine Learning or advanced EDA. Contains the primary `pre_ml.db` file.
- `valhalla_data/`: Docker volume directory exclusively used by the Valhalla routing engine container.
