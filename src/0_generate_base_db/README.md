# Step 0: Generate Base Database (`osm_analysis.db`)

This folder contains the foundational scripts that initialize the core spatial infrastructure for Portugal. These scripts extract, chunk, and process OpenStreetMap (OSM) data to build the spatial spine and Points of Interest (POIs) that later stages of the pipeline depend upon.

## Files

1. **`create_grid_spine.py`**:
   - Creates the official European Environment Agency (EEA) 1km x 1km grid spine for mainland Portugal (EPSG:3035).
   - Initializes the `osm_analysis.db` and stores the grid boundaries.

2. **`ingest_osm.py`**:
   - Reads the raw `.osm.pbf` file and chunks it into `osm_analysis.db`.
   - Generates the vital `roads_global`, `pois_global`, `lu_global`, and `nat_global` tables which are crucial for the later ML enrichment stages.

3. **`analyze_blocks.py`**:
   - The main orchestrator script that iterates over grid blocks and orchestrates the extraction of localized POI and road data.
   - Depends heavily on the bounding boxes generated by the grid spine.

4. **`process_cell_logic.py`**:
   - Contains the core processing logic imported by `analyze_blocks.py`.
   - Defines the precise filters and mapping logic to identify roads, restaurants, supermarkets, and other POIs from OSM data and ingest them into `osm_analysis.db`.

## Usage

These scripts should be run at the very beginning of the pipeline to seed `osm_analysis.db`. Run them in this order:

```bash
python3 create_grid_spine.py
python3 ingest_osm.py
python3 analyze_blocks.py
```

*Note: The later scripts in the `2_station_enrichment/` folder directly query the `osm_analysis.db` generated by this folder to enrich station configurations.*
